# 🤖 SmartSupport AI（カスタマーサポート自動分類＆一次対応支援ミニCRM）

Web系SaaS企業のカスタマーサポート（CS）現場における **「問い合わせの一次振り分けの属人化」「緊急障害の見逃し」「初動返信のリードタイム長期化」** を解決するために開発した、AI自動分類・回答案生成・リアルタイム通知機能付きのミニCRMアプリケーションです。

> 🔗 **関連ポートフォリオ（1作目）**：[android-emulator-load-test-monitor](https://github.com)（テスト自動化・異常検知・Webhook通知ツール）で培った「運用の自動化・アラート連携」の知見を、Webアプリケーション領域へと発展させました。

---

## 🎯 開発背景と解決した現場課題

自社開発SaaSのプロダクト成長に伴い問い合わせ件数が増加すると、CS現場では以下の課題が発生します。

1. **緊急障害の発見遅れ**：決済エラーやUI崩れなどの緊急連絡が、一般的な質問に埋もれて初動が遅れる。
2. **一次回答案の作成コスト**：毎回ゼロから丁寧なビジネスメール文面を作成・確認するのに時間がかかる。
3. **文脈・履歴の分断**：「一度完了にした不具合の再発」や「いつ・誰が対応したか」が追えず、二重対応や案内ミスが起きる。
4. **情報漏えい・誤操作リスク**：顧客向け受付画面と管理者画面の混同や、誤削除によるデータ消失。

これらを解決するため、**「AIによるトリアージ（緊急度・カテゴリ判定）」「緊急案件の即時Slack/Discord通知」「実務のセキュリティ・監査ログ設計」** を1つの軽量なWebアプリに統合しました。

---

## ✨ 主な機能・工夫したポイント

### 1. AI自動分類・緊急度判定・一次回答案生成（デモモード＆Gemini API両対応）
* 問い合わせ内容から **カテゴリ（不具合報告 / 料金・契約 / 機能要望 / その他）** と **緊急度（高 / 中 / 低）** を自動判定し、一次回答案（ドラフト）を自動生成します。
* **APIキー不要のデモAI判定モード** を標準搭載しているため、採用担当者様が環境変数やAPIキーを用意しなくても全機能を即座に体験できます（`.env` に `GEMINI_API_KEY` を設定すれば実APIへ自動切替）。

### 2. Discord / Slack リアルタイムWebhook連携
* 画面上からご自身の Discord / Slack Webhook URL を入力して **「📡 テスト送信」** で即座に疎通確認が可能。
* 緊急度「高」のお問い合わせが登録された瞬間に、指定チャンネルへリアルタイムで障害アラートを通知します。

### 3. 安全な自動返信シミュレーション機能
* 誤送信リスクを排除するため、実メールは送信せず、画面上のプレビューモーダルで宛先・本文を確認したうえで **「送信シミュレーション実行」** を行うと、ステータスが自動で「対応中」へ更新されます。

### 4. 実務のCS現場を想定したUX・セキュリティ設計
* **スクリーンショット自動リサイズ添付**：顧客がエラー画面を添付する際、ブラウザ側（Canvas）で横幅800pxへ自動圧縮して軽量保存・拡大プレビューが可能。
* **2要素照合による「前回の継続・再発」確認**：同じ会社の別担当者への履歴露出（情報漏えい）を防ぐため、**メールアドレス＋本人設定のパスコード（完全一致）** が揃った場合のみ過去の問い合わせ履歴を照合し、「前回の継続・再発か、別件か」を確認できます。
* **ロール分離ビュー切替**：ヘッダーのタブで **「🛠️ CS担当者ダッシュボード」** と **「👤 顧客用お問い合わせ窓口（他社チケット・管理機能を非表示）」** をワンクリックで切り替え可能。
* **対応履歴ログ（監査ログ）＆誤削除復元（Undo）**：「いつ・誰が・どのステータスへ変更したか」をタイムスタンプ付きで自動記録。さらに誤って削除した場合も画面右下のトーストからワンクリックでDBへ復元できます。

## 🛠️ 使用技術スタック

* **Backend**：Python 3 / FastAPI / SQLAlchemy / Pydantic / httpx
* **Database**：SQLite（サーバー構築不要で即座に永続化・デモ初期化が可能）
* **Frontend**：HTML5 / CSS3 (Tailwind CSS CDN) / Vanilla JavaScript (ES6+)
* **AI / Integration**：Google Gemini API（切替対応） / Discord & Slack Incoming Webhooks

## 🚀 ローカル環境での起動方法（Windows一発起動対応）

採用担当者様が手間なく動作確認できるよう、仮想環境構築からサーバー起動・ブラウザ表示までを自動化するランチャーを用意しています。

```bash
git clone https://github.com
cd smart-support-crm
```

### Windows の場合（推奨）
1. フォルダ内の **`start_demo.bat`** をダブルクリックします。
2. 初回のみ自動で `venv` 作成とパッケージインストールが行われ、ブラウザで `http://127.0.0.1:8000` が自動的に開きます。
3. 画面上部の **「🧪 サンプル問い合わせを自動入力」** や **「🔄 初期データにリセット」** を使って自由に操作をお試しください。

### Mac / Linux / 手動起動の場合
```bash
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
